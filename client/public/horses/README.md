# Horse artwork slots

placeholders (`HorseIllustration` / `RiderSilhouette`, built from stroked
SVG paths) instead of real illustrations, since the final artwork hasn't
been uploaded yet.

When the real ink-sketch artwork is ready (same art style across all four
horses, per the production spec — ivory background, black ink, no accent
color), drop the files here using these names and they can be swapped in
for the placeholder SVGs:

- `walk.png` — 평보, 1st horse (leftmost)
- `trot.png` — 속보, 2nd horse
- `canter.png` — 구보, 3rd horse
- `gallop.png` — 습보, 4th horse (rightmost)
- `walk-rider.png`, `trot-rider.png`, `canter-rider.png`, `gallop-rider.png`
  — the mounted rider scenes for each gait's final pose

Reference mood board (from the user): the existing 3-horse ink-sketch
gallop illustration is the basis for the art style; a 4th "walk" horse
needs to be added in the same style, and the smudged/motion-blur horse
sketch is a good candidate to inform the gallop treatment.
